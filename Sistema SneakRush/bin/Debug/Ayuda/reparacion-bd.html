Reparación de base de datos

Cada vez que alguien inicia sesión, el sistema comprueba que los datos no hayan sido tocados fuera del programa. Si encuentra una diferencia, el Administrador ve esta pantalla con las tablas afectadas y puede recalcular o restaurar un respaldo.

Dónde está: Aparece sola al iniciar sesión como AdministradorLo usa: AdministradorAtajo: F1
Esta pantalla no tiene captura. Solo aparece cuando hay una inconsistencia real en la base de datos, y no se puede provocar sin dañar los datos. Por eso acá se explica con texto.

Qué hace cada elemento

  • 1
    EncabezadoDice "INCONSISTENCIA PRESENTE EN LA BASE DE DATOS": el sistema detectó una diferencia entre los datos y su control de integridad.
  • 2
    Lista de inconsistenciasUna fila por cada problema: el ID del registro, la tabla afectada y qué pasó. Puede decir que el registro se insertó, se modificó o se eliminó directamente en la base de datos.
  • 3
    RecalcularVuelve a calcular los dígitos verificadores de las tablas afectadas, tomando los datos tal como están hoy. Pide confirmación. Si sale bien, avisa "Dígitos verificadores recalculados correctamente" y entrás al menú.
  • 4
    RestaurarPide confirmación y abre Gestión de respaldos para reemplazar toda la información actual por la de un respaldo (.bak).
  • 5
    SalirPide confirmación y sale sin reparar. Volvés a la pantalla de ingreso.

Cómo hacerlo

Por ejemplo, si vos mismo modificaste datos directamente en la base y sabés que están bien.

  1. Revisá en la lista qué tablas y qué registros figuran.
  2. Tocá Recalcular y confirmá.
  3. Cuando aparezca el aviso de éxito, el sistema te lleva al menú principal.
Tené en cuenta: Recalcular da por buenos los datos actuales. Hacelo solo si estás seguro de que nadie los alteró sin permiso.
  1. Tocá Restaurar y confirmá.
  2. En Gestión de respaldos elegí el archivo de backup (.bak) y tocá Restaurar.
  3. Se reemplaza toda la información actual por la del respaldo.
Tené en cuenta: Se pierde todo lo registrado después de la fecha del respaldo.

Reglas a tener en cuenta 3
  • La revisión se hace en cada inicio de sesión, y se registra en la bitácora de eventos.
  • Si quien inicia sesión no es Administrador, el sistema avisa "Se detectó un Error en el Sistema. Contacte al Administrador" y le deja solo el menú Usuario.
  • Esta pantalla solo muestra el problema: no cambia nada hasta que elegís Recalcular o Restaurar.
